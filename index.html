使用说明

DOCS
识别规则·配置项·数据去向

下文对识别、校对、配置及数据存放进行说明，问题排查请按此顺序执行。

01录入与识别

把当天的问题粘进输入框，一行一条，空行会自动跳过。点“识别”后按两轮匹配决定归属：

  • 先按板块关键词匹配，优先级数字小的板块先命中，命中即归属该板块；
  • 再在该板块的重点项关键词里找，命中一个就填进重点项；
  • 负责人先看楼层映射（例如含 B12 的归另一人），没命中就用该板块默认负责人。

识别只给初值，预览表每一格都能手动改；关键词没命中的行会留空，需要自己选板块。

粘进来的原文会先清洗再入库，序号、标点、括号备注、多余空格都不用自己动手删：

  • 去行首序号：1、 1. 1。 1！ 1； （1） (1) 都认，全角数字也算；
  • 去行尾标点：； ; 。 . ， 、 ！ ? 一律清掉，只留正文；
  • 去结尾括号备注：（已闭环）、（闭环时间11.10） 这类整段删除；括号在句子中间的不动，避免误删正文；
  • 空格归一：全角空格转半角、连续空格并成一个，中文与数字两侧的多余空格清掉，「B 厅 13 楼」记成「B厅13楼」，只有两个英文单词之间保留一个空格；
  • 板块、重点项、楼层负责人的匹配都不区分空格，搜索也忽略空格，输「B 厅 13」和「B厅13」结果一致。
清洗只作用在描述正文，时间列不会被改动；想保留原文就不要先清洗，直接手工录入。

02校对与同步时间

识别结果进预览弹窗，默认时间取当天。如果这批其实是昨天登记的，先改第一行的时间，再点“同步时间”，所有行一起变成这个值。

第一行留空时同步不会执行，会提示先填第一行。同步只改时间，不覆盖已选好的板块和负责人。

03配置板块

配置面板里每一项都能改：板块名称、板块关键词、优先级、负责人列表、默认负责人；进到单个板块还能维护它下面的重点项，以及“楼层 → 负责人”的对应关系。

  • 关键词逗号分隔，匹配用的是文本包含，短词容易误判，尽量用具体词；
  • 优先级 1 最优先，新板块默认 10，越靠后越不会被别的板块抢走；
  • 配置可导出成 json，换电脑时导入即可，不必重配一遍。

04数据与备份

台账记录与配置都存在本机浏览器的 localStorage 里，不上传服务器。清缓存、换设备、无痕模式，数据都不会跟过去。

  • “导出”把全部记录写成 xlsx，同时记下导出时间；
  • “导入”读入一个 xlsx 后会问：追加合并（保留原记录，新记录加在后面，五项全同的自动跳过不重复）或覆盖替换（清空原记录只留这个文件），换设备恢复旧表一般选覆盖；
  • “追加到文件”把当前记录续写到已有 xlsx 末尾，另存一份合并文件。
换电脑的顺序：旧机器先导出 xlsx 与配置 json，新机器先导入配置，再恢复台账。反了会出现板块对不上。

05常见问题

  • 板块是空的：这一行没有命中任何板块关键词，去配置里补关键词，或直接在预览里手选。
  • 负责人总是同一个人：检查该板块的楼层映射是否写全，没命中就落到默认负责人。
  • 导出的 xlsx 打不开：多半是浏览器拦截了下载，允许下载后重试。
  • 手机上表格显示不全：表格按桌面宽度排版，横向滑动查看全部列。

顺丰月结账单按姓名匹配部门，账单本身不含工号；到付单不自动计算，逐条由你决定加入账单还是删除。下面按实际操作顺序，把每个功能怎么用说清楚。

01上传两份表

工具要两份文件：一份顺丰月结原始账单，一份当月人员花名册。都支持 xlsx / xls / csv，点虚线框选择，或直接把文件拖进去。

  • 账单上传：放「① 上传顺丰月结账单」，账单至少要有运费金额、付款方式、寄件人姓名三列；账单没有工号，不用找工号列。有「运单号」列的话，到设置里把它指定出来，匹配会更准；
  • 花名册上传：放「② 上传人员花名册」，需要员工工号、员工姓名、行政组织名称三列；花名册自带运单号时，也到设置里把「运单号」指定出来；
  • 表头默认：账单默认把第 2 行当表头（顺丰原表第 1 行是合并大标题），花名册默认第 1 行，上传后直接解析，不弹窗问你选表；
  • 上传后区域下方会显示读到的行数与表头行，想确认读对没有，先看这一行；读不出表头（换个表头行、表里有多张工作表）会弹提醒，点「去字段识别」跳到设置，改工作表或表头行号，再点「按当前设置重新解析」；
  • 没有真实表格也能先试：点「这里载入演示数据排查一下」，会填一套 12 条账单 + 8 人花名册，跑完能看清整个流程；
  • 花名册只认「行政组织名称」这一列：拿完整路径去「设置 → 部门映射」里对同一字段，对上就直接取该行的核算组织编码与核算组织名称，花名册不用写编码；路径首尾多写的「/」、连续「//」会自动忽略。顺丰导出的路径和公司对照表层级不一致时，会逐级砍掉最前面一级再比（如「硬件工程系统/产品开发中心/产品开发二部/射频组」→「产品开发中心/产品开发二部/射频组」→「产品开发二部/射频组」），最多砍到只剩两级，仍然对不上才进未匹配、原因显示「未找到部门」。

02开始识别匹配与主界面

两份表都传好后，点「开始识别匹配」，全部重算一遍。三个按钮各管一件事：

  • 开始识别匹配：按当前配置重新跑一遍全部单据，改了规则、加了映射之后都要点它才生效；
  • 导出汇总 Excel：把当前结果导成 xlsx，随时可点，不影响数据；
  • 设置：打开五个页签（部门映射、人员映射、字段识别、人员类型、配置备份）的配置弹窗；

跑完先看三块信息，判断这一批对不对：

  • 本次匹配结果：一行摘要，写明匹配成功几条、内部员工几条、外包 / 供应商几条、到付待处理几条、未匹配几条；
  • 金额校验：一条校验条，把「原始金额 - 人工忽略金额」和「有效 + 未匹配 + 到付待处理 + 到付已删」对起来，显示「金额校验正确」说明这批数没有漏算、重算；显示「不匹配」就点开对照差额去找那几条单据；
  • 搜索框：按姓名、工号、部门、运单号筛当前标签里的行，例如输入「W」只看外包，输入「技术」只看技术部，右侧×清空即可恢复全部。

匹配按固定顺序走，前一步命中就不往下：人员映射 → 运单号 → 姓名 → 人员类型 → 部门映射。人员映射优先级最高：工号或姓名在人员映射里有一条记录，就以映射里的部门为准，花名册读出的部门不再覆盖它（想临时改一票，去明细清单「修改部门」即可，那条只改当行）。只有人员映射里没有这个人，才用花名册的部门去查部门映射。

  • 运单号优先：账单和花名册都指定了「运单号」列时，先按运单号在花名册定位到唯一那个人，同名同姓也能分开认，来源列标「运单号匹配」；运单号对不上或一个单号对应多人才继续往下；
  • 人员映射优先于人员类型、也优先于花名册部门：长期合作的外包人员提前录一条映射（工号或姓名 → 核算组织），之后同类单据直接自动归类，既不用每次人工确认，也不会被花名册里的旧部门覆盖；人员映射只在「设置 → 人员映射」里维护（新增 / 编辑 / 批量导入），匹配结果里不再自动写；
  • 按姓名匹配时忽略空格与全角，「张 三」和「张三」认作同一人。几千人的部门里有同名很正常，所以只要花名册里有部门就归入，不因同名、工号不同、部门不同拦人工：几个候选部门一致时标「同名·同部门」；只有一个候选有部门时标「同名·唯一部门」；分属不同核算组织时取花名册第一条的部门、标「同名·自动」，工号列同时列出全部候选供你核对。只有候选在花名册里全都没有部门，才进未匹配、原因「未找到部门」。唯一强制人工确认的情况：同一个工号在花名册里出现多条、且解析出多个不同核算组织（同工号挂两个核算组织属数据异常），这类进未匹配、原因「同工号·多个核算组织」，部门框已预选第一条；多条部门其实归同一核算组织时照常通过；
  • 人员类型按工号判定：规则表里勾了「外包 / 供应商」的类型（如 W 开头、7 开头）一律不自动归属，全部进未匹配清单，原因直接显示你起的类型名称；不在规则表里的工号段也不归属，原因显示「未知工号段」，去「人员类型」补一条就恢复自动匹配；
  • 部门映射按「/」层级逐级截头比对：先按完整路径找一模一样的，找不到就砍掉最前面一级继续找，一直试到只剩两级；命中多条同后缀时会拒绝自动归属，留给人工确认。控制台会打印每条单据试过的路径与命中的层级，方便核对；
  • 同一张运单号对应到花名册里多个人时，同样先看部门：部门一致就直接归集（来源列标「运单号·同部门」），不一致才进未匹配等人工确认；
表头名称和预设不一致会弹表头校验提示，去「设置 → 字段识别」手动指定列，再点「开始识别匹配」。

03五个结果标签怎么用

  • 部门汇总：只读的核算结果，一个部门一行，列是部门、部门编码、应付金额、不含税金额（应付 / 1.06）、税率、数量；要改数去明细或未匹配里调，这里不用手改；
  • 明细清单：匹配成功的单据（不显示人员类型，需要看类型去未匹配清单或搜索结果），最后的部门列叫「修改部门」，点开是带搜索的下拉面板，直接输部门名称或编码就能筛；三处清单的下拉都只显示「核算组织名称（编码）」，不再带小组后缀，选中后这一行立刻重算，只改这一行、不写人员映射；某行不该算进来，点「移出」；
  • 未匹配清单：放没认出来的单据，列里有工号（花名册）、姓名、人员类型、未匹配原因、金额。能按花名册路径查到核算部门的，部门框已经预选好，核实后点「保存」这条直接进明细清单（不再问「是否写入人员映射」，人员映射统一去设置里手动维护）；嫌逐条点麻烦就点右上角「按预选批量归入（N 条）」一次全归。只有「花名册部门在部门映射里查不到」这一种情况，保存时才弹「是否绑定部门」：确认绑定＝把这条花名册路径写进部门映射、下次同路径自动匹配；仅本次生效＝不写映射、这条照样进明细。保存任何一条后，同一花名册路径的其他未匹配行会自动预选同一个核算组织，接一次批量归入就行。公共账号（前台 O / F 之类）特殊：不按规则自动预选、也不弹绑定，每单自己选；但你给其中一条选好部门保存后，同路径的其他公共账号行会自动预选成同一个核算组织，同样不写部门映射。「未匹配原因」和「人员类型」内容相同时（比如都是外包员工、公共账号）只显示「/」，不重复写；整条不该算的就点「忽略」；
  • 到付清单：付款方式含「到付」的单据不自动匹配，全部集中在这里。选好部门点「加入账单」才计入汇总；同名多行（同一个人有好几票到付）只要给第一行选定部门，后面同名且还没选的行会自动预选同一个核算组织，逐个点「加入账单」即可；不需要的点「删除」，删错了在同一行点「恢复」可以撤回；
  • 搜索结果：顶部搜索框作用于当前标签，配合部门下拉一起用，能快速定位某个人、某个部门或某张运单的单据。

04设置五个页签怎么用

  • 部门映射：一条记录三个字段——核算组织编码、行政组织名称、核算组织名称，照公司给的核算对照表填。新增就填三个框点「保存」，改内容点该行「编辑」，不要的点「删除」；行政组织名称不能重复，核算组织编码可以多条共用（多个分部门归同一个核算组织），核算组织名称留空会自动用行政组织名称顶上。行政组织名称是匹配键，必须是花名册里的完整路径。表格上方搜索框按编码或名称筛，右侧显示共几条、筛出几条；
  • 部门映射批量导入：公司给了核算对照表就点「批量导入映射表」，读三列的 Excel / CSV，单元格里的全角空格、不换行空格、零宽字符、多余换行会自动清洗，合并单元格会按左上角展开，表头最多往下找 20 行，工作表也会自动挑带这些列名的那张；同一「行政组织名称」更新内容，新路径追加，空行跳过；导入完弹窗给出读取 / 新增 / 更新 / 跳过条数与跳过行号，可导出失败明细 CSV 核对；没有现成表点「下载模板」按三列示例填；旧的两列「编码 + 名称」文件也能导，名称会同时当行政组织名称与核算组织名称；
  • 人员映射：工号或姓名 → 部门，保存后立刻对结果生效，优先级高于人员类型。新增、编辑时部门选择旁有搜索框，输部门名称或核算组织编码就能筛，只剩一个结果会自动选上；表格上方搜索框按工号 / 姓名 / 部门筛；批量做点「批量导入映射」（工号、姓名、部门编码三列，可点「下载模板」），要重来点「清空数据」；
  • 字段识别：账单和花名册各选一次工作表和表头行，再把六个字段的下拉对上——运费金额、付款方式、寄件人姓名、运单号（账单侧），员工工号、员工姓名、行政组织名称、运单号（花名册侧）。导入后会自动按常见列名预选：账单认「应付金额 / 付款方式 / 寄件人 / 运单号码」，花名册认「工号 / 寄件人姓名 / 部门 / 运单编号」（表头写「费用归属部门名称」「行政组织名称」也能认）；表头换了名字就在这里手动指，改完点「按当前设置重新解析」；
  • 人员类型：规则表默认是空的，第一次用要按贵司工号规则自己加（例如「前缀 W → W外包，需人工确认」和「工号长度 8 → 内部员工」）。一张从上到下依次判断的规则表，第一条命中即生效，所以前缀规则要排在长度规则前面。新增：选匹配方式（前缀匹配 / 工号匹配（完全相同）/ 工号长度）→ 填值 → 填类型名称（这个名字会直接显示成未匹配原因）→ 选是否外包 / 供应商，点「添加规则」。已有规则可「上移」「下移」调顺序，不要的点「删除」；点「载入示例规则」可以一次性得到 W / V / F 前缀 + 8 位工号这套常用设置再按需改。规则为空或某个工号哪条都没命中时，该单据一律进未匹配并标「未知工号段」；勾了外包 / 供应商的类型一律需人工确认部门；
  • 配置备份：点「一键导出备份」存成一个 json，部门映射、人员映射、人员类型规则和表结构（账单 / 花名册的工作表与表头行）整套打包；换电脑、或浏览器清理记录后，点「一键导入备份」选这个文件，再选「合并导入」（保留现有配置，同编码同类目用备份里的更新）或「覆盖导入」（清空后整体恢复）即可。备份建议放桌面或网盘，清理浏览器记录前先导出一份。注意列级字段识别不在这份备份里，换表头名字仍要在「字段识别」里重设。

05导出、数据与常见问题

点「导出汇总 Excel」生成 xlsx：部门汇总、明细清单、未匹配清单、到付清单（含每条的处理状态：待处理 / 已加入账单 / 已删除）；有手工忽略的行会多一张「人工忽略清单」。明细清单按原账单整行照搬，列顺序不变，只在末尾补工号（花名册）、部门编码、部门名称三列，不再导出部门配置表。

配置与映射都存在本机浏览器里，不上传服务器：清缓存、换浏览器、无痕模式都不会跟过去，换设备前先导出一份配置备份。

  • 大半记录进未匹配：先核对花名册的行政组织名称和「部门映射」里的行政组织名称，首尾斜杠会自动忽略，但空格、括号、层级文字、全角半角必须一致；再查姓名有没有多余空格或重名；
  • 明明路径一样却没匹配上：把两边路径复制出来逐段比对，常见是多一个空格、括号用了全角、或层级名称写的是简称；
  • 到付单没进到付清单：检查「付款方式」列有没有在字段识别里指对，只有含「到付」两个字的才进到付队列；
  • 改了规则不生效：人员类型、部门映射改完后要点一次「开始识别匹配」才会重算；
  • 金额校验不匹配：说明有单据没落进四个去向，先看是不是有行被作废后又改了部门，重跑一次识别即可复原；
  • 手机上表格显示不全：表格按桌面宽度排版，横向滑动查看全部列，逐条处理建议在电脑上做。
